# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **[info@proaiassistant.com](mailto:info@proaiassistant.com)** with:

- A short description of the issue
- Steps to reproduce (if possible)
- Impact you expect
- Whether you have a suggested fix

We will acknowledge the report and work with you on next steps. Thank you for helping keep learners and operators safe.
